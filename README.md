# DompetKu

DompetKu adalah aplikasi pencatat keuangan pribadi berbasis web. Aplikasi ini dibuat untuk membantu mencatat pemasukan, pengeluaran, hutang piutang, target tabungan, dana wajib, dan beberapa dompet keuangan dalam satu tempat.

## Link Aplikasi

Buka aplikasi di: https://azbhy24.github.io/dompetku/

## Fitur Utama

- Catat pemasukan dan pengeluaran harian
- Kelola kategori transaksi
- Pantau saldo dan target saldo
- Kelola hutang dan piutang
- Buat target tabungan pribadi
- Kelola dana wajib dengan deadline
- Pisahkan saldo ke beberapa dompet, seperti operasional, darurat, investasi, dan bisnis
- Lihat ringkasan dan grafik keuangan
- Export dan import data lokal
- Mode terang dan gelap

## Catatan

DompetKu berjalan langsung di browser dan menyimpan data secara lokal di perangkat pengguna. Karena belum memakai backend, data tidak otomatis tersinkron antar perangkat.
